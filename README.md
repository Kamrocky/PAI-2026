# Aplikacja budżetowa

Aplikacja internetowa do zarządzania finansami osobistymi. Użytkownik może dodawać konta, kategorie i transakcje oraz analizować swoje wydatki i przychody na dashboardzie.

## Stack technologiczny

- Python
- Django
- Django Ninja
- PostgreSQL
- HTMX
- Tailwind CSS
- Docker Compose

## Główne funkcje

- Rejestracja i logowanie użytkowników
- Zarządzanie kontami finansowymi
- Kategorie przychodów i wydatków
- Dodawanie i przeglądanie transakcji
- Dashboard z podsumowaniem finansów
